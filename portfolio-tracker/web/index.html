ESP32-2432S028R

Portfolio tracker

A desk display for a portfolio of securities: the total value, a chart of the last two weeks, and a scrollable list of every holding with today's change. Tap a holding to see its own chart. Prices come straight from the Yahoo Finance API over Wi-Fi — no account and no API key.

Your browser does not support Web Serial. Use Chrome or Edge on a computer (not mobile).

2. How to

  1. Open this page in Chrome or Edge on a computer and plug the CYD into USB.
  2. Click Install and choose the serial port (CH340/CP2102).
  3. When the install is done, enter your Wi-Fi. It is used for prices and updates.
  4. The tracker fetches portfolio.json and the prices, then shows the overview.

Updates: tap the i button, then UPDATE FW. The tracker checks this site and installs a newer version over Wi-Fi.

Your holdings

The device reads portfolio.json from this site every time it refreshes, so changing your portfolio means editing that file in the repository and pushing to main — no reflash.

{
  "base": "DKK",
  "holdings": [
    { "ticker": "NOVO-B.CO", "qty": 40 },
    { "isin": "US0378331005", "qty": 12, "name": "Apple", "currency": "USD" }
  ]
}
tickerA Yahoo Finance symbol: NOVO-B.CO, AAPL, VWCE.DE, IWDA.AS. Look it up on finance.yahoo.com if you are unsure.
isinUsed instead of ticker. The device looks the symbol up once and remembers it. A ticker is more reliable — the lookup endpoint rate-limits.
qtyHow many you hold. Fractions are fine.
nameOptional display name. Defaults to the one the API reports.
currencyOptional. Giving it saves one API call per holding on the first boot.
baseThe currency everything is converted to. FX rates are fetched for the same days, so the chart is right for a mixed-currency portfolio.

This repository is public, so whatever you put in portfolio.json is public too.

Using it

OverviewTotal value, today's change, and the last two weeks of the portfolio's value.
ListDrag to scroll. Each row shows the value in your base currency and today's change in %.
HoldingTap a row for its own chart, switchable between 2W and 1M, plus price, value and weight.
StatusThe i button: firmware version, FX rates, how old the prices are, refresh and firmware update.
RefreshAutomatic every 5 minutes, or on demand from the status screen.
