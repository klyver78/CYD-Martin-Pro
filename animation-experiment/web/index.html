CYD Animation experiment

How smooth can a Cheap Yellow Display animate? Each ROM runs the same set of FPS tests with a different graphics library. Flash one here, then switch between ROMs over Wi-Fi from the device itself.

Your browser does not support Web Serial. Use Chrome or Edge on a computer (not mobile).

2. How to

  1. Open this page in Chrome or Edge on a computer and plug the CYD into USB.
  2. Pick a ROM above, click Install and choose the serial port (CH340/CP2102).
  3. When the install is done, the flasher asks for your Wi-Fi. Wi-Fi is needed to switch ROMs later; the tests themselves run without it.
  4. On the screen, pick a tab and a test. The FPS is shown top-left. Tap the screen to get back to the menu.
  5. Bench runs every test for 3 seconds and shows a results table (also printed on the serial port at 115200 baud as a Markdown table).
  6. ROMs downloads the ROM list from this site and installs the one you tap over Wi-Fi (OTA). Wi-Fi settings are kept.

If a ROM leaves the screen garbled (for example the 80 MHz one on a panel that can't keep up), you can't use the on-screen menu. Just flash another ROM from this page.

What the tests do

TabTestWhat it shows
RawFill screen, Strips, Strips DMA, Rects 32px, SPI sweep* The ceiling: how many full frames per second the SPI bus can carry, with and without DMA. *LovyanGFX only.
BallsDirect, Full frame, Dirty rects 1–400 bouncing balls (+/− at the bottom) drawn three ways: straight to the panel, whole frame in RAM strips, or only the changed boxes.
FXPlasma, Plasma 1/2, Fire, Starfield, Rotozoom Every pixel computed by the CPU each frame. Shows when the CPU, not the bus, is the limit, and what half resolution buys.
UIGauge, Eye, Scroll list, Counter Realistic dashboard-style animation: partial updates of a dial or an eye, a smooth full-screen scroll, big text.
LVGLWidgets, Meter, Scroll list, Full redraw, Moving objs, Big text The same kind of things with LVGL 8.3, so you can see the price of a UI framework.
