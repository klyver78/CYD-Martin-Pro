# CLAUDE.md — CYD-experiments

Experiments for the ESP32 "Cheap Yellow Display" (ESP32-2432S028R, landscape 320x240).
One folder per experiment; everything (code, comments, UI) in English.

## Repo layout
- `<experiment>/` = PlatformIO project + `VERSION` + `roms.json` + `web/index.html`.
- `tools/build_site.py` builds every experiment folder (needs `roms.json` + `platformio.ini`) and
  assembles `_site/`; `.github/workflows/pages.yml` runs it and deploys to GitHub Pages
  (https://martindamp.github.io/CYD-experiments/). Release = bump the experiment's `VERSION`, push to `main`.
- `site/index.html` = overview page (reads `experiments.json` generated by the script).

## animation-experiment
- ROMs = PlatformIO envs (`tftespi`, `tftespi80`, `lovyangfx`, `lvgl`), selected with
  `build_src_filter`; each must also be listed in `roms.json` (keep `desc` <= 48 chars).
- `src/common/`: shell shared by all ROMs (menu, touch, Improv Wi-Fi, bench, OTA ROM switcher via
  `PAGES_BASE` in `board.h`, cert-validated with `ota_certs.h`). The shell draws through the
  `Display` interface + the software `Canvas` only, so it works with any graphics library.
- `src/gfx/`: `display_tft.cpp` / `display_lgfx.cpp` backends (guarded by `GFX_TFT` / `GFX_LGFX`),
  `scenes.cpp` = all scenes, `SCENES` table. Scenes must free everything in `end()` (TLS needs the heap).
- `src/lvgl/main.cpp`: LVGL 8.3 ROM (`GFX_LVGL`), reuses `display_tft.cpp`; config in `include/lv_conf.h`.
- Pixel buffers are byte-swapped RGB565 (`rgbBE`, `swap16`) so DMA sends them as-is.
- Panel: ILI9341_2 init, BGR, inversion ON, MADCTL=MV (LovyanGFX `setRotation(5)` matches TFT_eSPI rotation 1).
- `src/build_version.h` is generated in CI and .gitignored.
- Screenshots: `tools/sim/render.sh` -> `docs/*.png` (mock headers in `tools/sim/mock`).
- The cloud sandbox can't download PlatformIO's toolchain; a local arduino-cli build with esp32 core
  2.0.17 (same core PlatformIO uses) works for compile checks (pass the platformio.ini flags as
  `build.extra_flags`).

## space-game (Star Ring)
- Single env `game`, TFT_eSPI at 80 MHz, 6 x 320x40 static strip buffers pushed with DMA (startWrite held).
- `src/game.cpp` = all logic + rendering, hardware-free (polar coords around CX/CY, ring radius R);
  `main.cpp` feeds `GameInput` (left/right third -> turn, middle third -> fire, press -> tap) and dt.
  Enemies + power-ups are shielded inside `IMMUNE_R`; weapons GUN/SPREAD/LASER/GRENADE from power-ups. `net.cpp` = Improv + OTA
  (compares `roms.json` version with FW_VERSION_SEM, installs `roms/game/firmware.bin`).
- `src/canvas.h` is a copy of animation-experiment's (+ fillTriangle); keep fixes in sync.
- Screenshots: `tools/sim/render.sh` runs game.cpp with scripted input -> `docs/*.png`.
